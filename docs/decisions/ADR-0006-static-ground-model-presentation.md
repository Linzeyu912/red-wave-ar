# ADR-0006：手绘触发图后的静态地面与模型呈现

> 日期：2026-08-06
> 状态：`ACCEPTED`
> 取代：ADR-0003、ADR-0005 中“真实照片展示卡＋`photo_emerge` 自动播放”的平台呈现部分。

## 背景

Kivicube 的分段动画调用与跨端表现目前不够明确，不能把“先显示原图、再播放模型展开动画”当成稳定上线前提。原方案还将地面作为照片平面的附属物，容易让独立 GLB 的底部与地面材质断开。

## 决策

九个触发单元统一使用以下稳定流程：

1. 扫描原红白手绘触发图；
2. 识别稳定后显示该单元的 `ground_texture_v002.png` 方形、Unlit 地面平面；
3. 同时显示静态 GLB，明确关闭 `photo_emerge` 自动播放；
4. 约 0.8 秒后播放旁白。

绘制触发图时使用的真实照片仍保留为内部建模、形象核对和触发图来源依据，但不再作为识别后的 AR 图片平面，也不构成公开上线的前置图片资产。

每张 v002 地面贴图都按模型底部材质选择同一材料族，并经过两项衔接处理：轻微底材色桥接，以及仅在模型实际占地边缘可见的软接触阴影。地面平面保持 1:1、不拉伸、四周留出 0.10 目标单位边界；模型最低点保持本地 `Y=0`，场景中地面为 `Y=0.002`、模型为 `Y=0.004`。

## 结果

- Kivicube 的首轮验证只需检查“识别 → 地面 → 静态模型 → 旁白”，不依赖图片淡入或 GLB 入场动画。
- `reference_reveal_v001.jpg` 仅改作内部绘图参考副本，不能被配置为 AR 展示对象。
- 任何模型底部材质、占地或缩放调整后，必须连同对应 v002 地面、接触边缘和 `kivicube_setup.json` 一起复核。
- 默认不添加通用厚展台；建筑自身台阶、城墙、雕塑底座和天线基座仍属于模型本体，可保留。

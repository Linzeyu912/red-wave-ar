# ADR-0003：手绘触发图、真实照片与真实配色模型分段呈现

> 日期：2026-07-29
> 状态：`SUPERSEDED_BY_ADR-0006`
> 说明：触发图、真实照片与模型仍须保持来源对应；但真实照片不再作为识别后的展示卡。

## 背景

“红色电波实践路线”的触发图采用红、白为主色的手绘视觉语言，用于保持路线整体风格统一；地点模型则需要按真实建筑颜色和材质呈现。若识别后直接从红白手绘图切换到真实配色模型，用户可能难以理解二者的对应关系，也可能误把手绘配色当作建筑原貌。

## 决策

Kivicube 平台线的七个地点统一采用以下顺序：

1. 扫描红白手绘触发图；
2. 识别成功后展示绘制该触发图时使用的真实参考照片；
3. 真实照片保留在触发图上方，地点 GLB 从照片中的主体下缘贴地展开；
4. 模型稳定出现后开始或继续旁白。

触发图、真实照片和模型是三件独立资产：

- 触发图负责识别和项目视觉统一；
- 真实照片负责建立手绘形象与真实地点之间的对应关系；
- 模型负责真实配色的三维展示和后续互动。

模型不从红白触发图取色。真实照片只有取得公开展示许可并完成隐私检查后，才能进入平台交付；内部建模参考许可不能替代公开展示许可。

## 结果

- 每张资产卡必须分别记录触发图、真实照片展示图和 GLB 的文件、来源、权限与审核状态。
- 每个地点必须验证完整的“触发图—照片—模型—旁白”流程，而不能只验证 GLB 是否可上传。
- 手绘触发图需要同时满足红白视觉规范和 Kivicube 图像识别要求，必要时可增加非对称线条与局部细节，但不改变总体风格。
- 若某张真实照片未取得公开展示许可，该地点不能按本流程发布；应补拍自有照片、取得授权或更换可公开素材。
- 具体性能、格式和真机验收标准以 [`../KIVICUBE_ASSET_CONSTRAINTS.md`](../KIVICUBE_ASSET_CONSTRAINTS.md) 为准。
- 照片平面、主体锚点、模型动画和底部衔接的具体实现由 [`ADR-0005`](ADR-0005-photo-plane-model-emergence.md) 细化。

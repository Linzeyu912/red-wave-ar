# 建模主体身份与公开资料核验

> 状态：`PUBLIC_SOURCE_REVIEWED / MODELING_SCOPE_DECIDED / S3_IDENTITY_CONFIRMED / V2.3_MAPPING_RECONFIRMED`
> 初次核验：2026-07-29；原位复核：2026-08-04；S3 身份补充：2026-08-16
> 适用范围：S1–S7 的主体命名、建模提示词、旁白事实核验

本文件只回答两件事：同一地点的现有图片是否指向同一主体，以及公开资料能否证明该主体的地点身份。建筑形态仍以受控参考照片和对应 `visual_constraints.md` 为准；公开网页没有描述到的门窗、背立面和细部，不得反向补写为“官方复原”。

2026-08-04 重新逐图核对后，九个单元的主体映射未发生改变。2026-08-16，项目负责人确认 S3 为“短波通信局旧址”；检索到的工信部国家工业遗产名录和中国电信博物馆资料将正式史料名称对应为“北京国际电台中央发信台”。旧有“第三电台”“五六四台”等搜索线索仍不采用。

## 使用规则

1. `IDENTITY_VERIFIED` 只说明地点或纪念主体身份有公开资料支持，不等于所有建筑细节均已被外部资料证明。
2. S3 的项目展示名使用“短波通信局旧址”，正式史料名称记录为“北京国际电台中央发信台”；两件模型继续使用稳定的 S3A/S3B 文件名，不因身份补充而重命名。
3. S5 的《家国》是语义标题。按正面实物传统右起横排时，从画面左至右会看到“国、家”，不得因此在元数据中误写成“国家”。
4. S7 不混合不同时期标识：入口横向馆名可以保留，高塔竖向企业标识必须作为独立材质或贴花，在最终导出前选择保留或移除。

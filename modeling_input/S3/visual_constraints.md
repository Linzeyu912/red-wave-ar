## 2. S3A 通信楼

### 2.1 主体边界

- `OBSERVED`：中央多层圆角玻璃塔、其右后方高直矩形墙体、左右低层翼楼和正面入口台阶。
- 左侧现代通信杆同时出现在触发图和照片中，但是否属于本次历史主体尚未确认；V1 默认不与楼体合并。
- `EXCLUDED`：前景水池、树木、车辆、旗帜、临时遮阳棚、外露电线、现代运营商文字和场地灯具。

### 2.2 可见体块与比例

- 中央塔为高而窄的多层体量，正面与两侧转角采用连续圆角/多折面玻璃，形成近半圆或多边形凸出轮廓。
- 每层由明显外挑的水平楼板带分隔，楼板边缘呈褪色粉橙/浅砖红；连续水平线是最强识别特征。
- 玻璃带之间有浅灰竖向混凝土柱和深色细窗框，窗格不完全一致，可做规则化简化。
- 右后方是一块更朴素的高直矩形墙体，表面为严重风化的灰白砖/抹灰，少量侧向窄开口，不添加触发图中的红色“短波通信局”文字。
- 底部是一至两层横向展开的灰白翼楼，平屋顶和粉橙色檐边，前方有矩形窗、入口和宽台阶。
- 建筑整体具有上世纪通信工业建筑的功能主义体块感，应保持老旧但可辨识的真实状态。

### 2.3 材质与真实配色

- 主墙与翼楼：灰白色旧砖、旧抹灰或旧混凝土，明显斑驳、泛灰、局部脱落；风化纹理需原创概括。
- 水平挑檐：褪色粉橙、浅砖红或旧肉粉色，边缘有污渍但不做鲜艳红色。
- 窗：灰绿、蓝灰或暗绿色旧玻璃，深灰/褐色细框，不使用镜面蓝玻璃幕墙。
- 高直墙体：浅灰白、旧砖纹理明显，局部深灰污迹；平屋面为灰色。

### 2.4 必须保留的识别细节

- 连续多层圆角玻璃带与粉橙水平挑檐；
- 圆角塔和右后方高直墙体形成的“软曲线—硬直面”对比；
- 底部低矮横向翼楼与中央竖塔的层级；
- 老旧、斑驳但非废墟化的材质状态。

### 2.5 推断、差异和禁止

- 背面、屋顶和塔体内部均为 `INFERRED_LOW_DETAIL`；不补室内设备或不可见窗列。
- 左侧环形构件通信杆若确认保留，应作为可删除附件、简化为浅灰杆体与两层圆环，不带“中国移动”等运营商标志。
- 不把触发图上的红色名称当成立面真实标牌，不新增霓虹字或现代玻璃幕墙。
- 不逐根复刻外露电缆、空调、管线和旧支架。

### 2.6 可直接复用的提示词片段

## 3. S3B 天线阵列

### 3.1 主体边界

- `OBSERVED`：一座中央竖向钢桁架塔、四向交叉的长三角桁架臂、端部拉索和悬挂式细线阵列。
- 每个触发图只制作一套完整代表性阵列；照片中可能出现的相邻第二套结构不进入同一模型。
- `EXCLUDED`：树冠、天空、鸟巢、鸟类、场地基础之外的建筑和植被。

### 3.2 可见结构

- 中央支撑为细长四边形钢桁架塔，采用重复三角斜撑，塔顶附近连接旋转/支承节点。
- 四根长桁架臂在水平面形成 X 形或十字形交叉；每根臂由上下弦和重复三角腹杆构成，端部略收细。
- 多组细线从桁架臂向下或向相邻方向悬挂，形成层叠的扇形、菱形和近帘幕状线网。
- 线缆上可见少量绝缘子/连接点；V1 只保留能定义线网轮廓的代表性节点。
- 结构颜色以深棕黑、锈褐和灰色金属为主，不做明亮新钢材。

### 3.3 移动端简化优先级

1. 必须保留中央塔和四根交叉长桁架臂；
2. 每根臂保留清晰三角腹杆节奏；
3. 保留外缘线、主下垂线和数条横向联络线，建立天线帘幕轮廓；
4. 次级细线、微小绝缘子、鸟巢和重复连接件可删除；
5. 细线必须有移动端可见厚度，不用零宽度曲线，不形成实心膜面。

### 3.4 推断与禁止

- 只依据可见照片制作代表性线网，不声称每根天线线缆数量和连接点与实物一致。
- 中央转轴、地脚和不可见背面按简单机械体块闭合，标记 `INFERRED_LOW_DETAIL`。
- 不做起重机吊钩、输电塔横担、高压绝缘串、雷达抛物面或实体布幕。
- 不制作照片中的鸟巢。

### 3.5 可直接复用的提示词片段

> 轻量写实的参考素材所示历史通信天线阵列，一座细长灰色钢桁架中央塔，塔顶连接四根在水平面交叉成 X 形的深锈褐色长三角桁架臂，桁架臂具有规则三角腹杆并向端部略微收细；从各臂悬挂多组有轻微弧垂的细金属线，组成分层扇形和菱形帘幕式天线网，少量深色绝缘连接点。优先保留中央塔、四臂轮廓和主线网，简化次级细线，金属表面旧而不破损，不包含树木和天空，不附会具体台站身份。

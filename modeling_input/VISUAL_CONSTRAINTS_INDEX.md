## 1. 标记含义

- `OBSERVED`：在一张或多张照片中直接可见，可作为 V1 主要形象约束。
- `INFERRED_LOW_DETAIL`：照片没有覆盖，只允许用连续材质和简单体块保守闭合。
- `EXCLUDED`：人物、车辆、花束、树木、旗帜等临时或环境元素，默认不进入主体模型。
- `PENDING_CONFIRMATION`：不同照片存在年代或状态差异，不能由建模模型自行选择。
- `IDENTITY_PENDING`：图片内部主体一致，但公开资料尚不能证明具体地点或台站身份。

红白手绘触发图只用于轮廓对应和识别，不提供模型颜色。真实配色必须来自真实照片；原照片也不得未经许可直接投影、烘焙或复制为纹理。

## 3. 建模提示词组装顺序

后续给建模模型写提示词时，建议按以下顺序从对应场景文档复制信息：

1. 写明单元 ID、唯一主体和是否包含基座；
2. 描述正面主轮廓、体块层级和最强识别特征；
3. 写真实材质与配色，不引用触发图的红白配色；
4. 列出必须保留的牌匾、钟面、人物姿态或结构件；
5. 明确不可见面均为 `INFERRED_LOW_DETAIL`；
6. 写默认排除项和场景专属负面词；
7. 最后附 Kivicube 运行预算：单个 GLB 优选 ≤5 MB、验收 ≤10 MB，网格/材质/贴图各不超过 10；通用模型规范为 300,000 三角面以内，项目按主体设置更低的证据驱动上限，详见 `DETAIL_EVIDENCE_MATRIX.md` 与 `docs/KIVICUBE_ASSET_CONSTRAINTS.md`。

## 4. 跨场景统一负面约束

- 不建天空、树木、山体、游客、车辆、围栏、花束、临时旗帜、灯杆和拍摄水印；
- 不把手绘触发图的红白画风、线稿阴影或纸张背景带入真实配色模型；
- 不从单张正面照片臆造完整背立面、室内、屋架、结构节点或历史装饰；
- 不把照片中的透视畸变、遮挡、强光、高光和阴影烘焙进基础颜色；
- 不新增照片中不可见的文字、人物、门窗、雕花、设备和企业标志；
- 不声称是 1:1 复原、测绘模型或完整数字孪生。

# 七个地点文字素材：研究稿索引

> 状态：`RESEARCHED_DRAFT / INTERNAL_REVIEW_REQUIRED`
> 更新日期：2026-08-06
> 用途：为 Kivicube 的旁白、信息卡和汇报材料提供统一的“长版＋短版”文字基础；**不是已审核的对外成稿**。

## 使用方式

1. 每份稿件都按平西已有 Word 的结构整理为长版和短版，并补充模型对应、可追溯来源及不得扩写的边界。
2. 通过项目内容审核后，才将选定文字复制、压缩到相应 `lkivivube_delivery/scenes/*/narration/narration_v001.md`，并在资产卡中记录审核人和日期。
3. 这些文件是可编辑的研究稿；原始 Word 和图片仍保留在各地点的 `local_reference/`，不可把“已入库”理解为“已具备公开展示许可”。

- 场景范围与九个模型单元以 [`../docs/PROJECT_DIRECTION.md`](../docs/PROJECT_DIRECTION.md) 和 [`REFERENCE_INVENTORY.md`](REFERENCE_INVENTORY.md) 为准。

# S4 居庸关：文字素材研究稿

> 状态：`RESEARCHED_DRAFT / OFFICIAL_SOURCES_LINKED / INTERNAL_REVIEW_REQUIRED`
> 对应模型：S4A 居庸关城楼。

## 长版（审核前基础稿）

居庸关位于北京西北方向的峡谷要冲，是长城沿线著名的关城。北京市园林绿化局资料记载，现存遗址以明代建筑为主，城周跨翠屏、金柜两山之间；南北翁城、城楼、敌台、水门等设施共同构成了完整而严密的防御体系。关内的云台还保留元代石雕与多种文字经文，是认识古代建筑、宗教艺术和多民族文化交流的重要遗存。

本模型以照片中带“天下第一雄关”匾额的城门台和上部城楼为主体。它适合从“关隘、城门、城楼与防御体系”讲述长城的空间逻辑；周边山体、长城延伸段和院落仅作环境，不应被描述为本次模型的完整复原。

## 短版（审核前基础稿）

居庸关是北京北部的重要长城关隘。城门、翁城、敌台和水门相互配合，构成层层设防的关城体系。眼前的城楼与“天下第一雄关”匾额，正是这条山谷通道的历史标记。

## 模型与文案对应

- 可讲述：关隘位置、明代现存建筑、防御体系、云台的文化价值。
- 可观察：牌匾、券门、城台、上部城楼和照片可见的彩画关系。
- 不应扩写：不可见区域的彩画、城内功能建筑的具体位置，或未有来源支持的单一战事细节。

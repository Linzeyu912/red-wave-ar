# S6 香山镇芳楼：文字素材研究稿

> 状态：`RESEARCHED_DRAFT / OFFICIAL_SOURCES_LINKED / INTERNAL_REVIEW_REQUIRED`
> 对应模型：S6A 香山镇芳楼。

## 长版（审核前基础稿）

香山是中共中央进驻北平、筹建新中国的重要革命旧址区域。北京市公园管理中心的香山资料将镇芳楼、镇南房列为中共中央办公厅机要处旧址，与香山专用电话局等通信保障点位共同构成这段历史的空间线索。

本模型聚焦照片中的镇芳楼外观：灰砖楼体、环廊、山花五角星和门窗节奏共同构成可识别的建筑形象。讲解应从“机要工作、通信保障与严守保密”切入，说明一座建筑如何承载组织运转中的无声工作；没有照片或公开资料支持的室内布局、办公设备和具体人员，不应补写为史实。

## 短版（审核前基础稿）

香山镇芳楼、镇南房曾作为中共中央办公厅机要处旧址。这里的通信与机要工作并不喧闹，却连接着筹建新中国时期的重要信息保障。眼前的建筑，留下了这段严谨而无声的历史印记。

## 模型与文案对应

- 可讲述：香山革命旧址背景、机要处旧址、通信与机要保障主题。
- 可观察：灰砖立面、环廊、山花五角星、门窗与屋顶的照片可见特征。
- 不应扩写：房间分配、专线号码、值班人员或照片看不到的结构细节。

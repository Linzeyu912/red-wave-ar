## 2. S5A 主体边界

- `OBSERVED`：四尊独立浅灰石雕人物、后方宽幅浅浮雕墙、人物脚下低台、前方斜置深色铜牌及石质底座。
- V1 建议把上述元素作为一个完整纪念雕塑组合，但可拆分为“人物”“浮雕墙”“铜牌/底座”三个网格以便减面和材质管理。
- `EXCLUDED`：鲜花、花圈、祭扫物品、树木、山坡、天空、游客、现场灯光、水印和大面积广场铺装。

## 3. 四尊人物

从观众视角由左至右：

1. 男性，短发，穿长外套/中式上衣与长裤，双臂交叉于胸前，双脚自然分开；
2. 女性，短发或盘发，穿及膝连衣裙/旗袍式长裙和肩部披巾，双手在腹前交叠，姿态端正；
3. 男性，穿西装、衬衫和领带，一侧前臂搭着外套或长衣，另一只手靠近身前，站姿笔直；
4. 男性，穿衬衫、马甲和长裤，双手自然插入口袋或靠近裤袋，姿态较放松。

人物为写实纪念雕塑比例，面部和手部需保留可读轮廓，但不追求毛孔、指纹或完整不可见背部服饰。每尊人物脚边有不规则石质支撑/背景体，可作为结构支点概括。

## 4. 浮雕墙与前置铜牌

- 浮雕墙是横向宽幅、略有分折或分板的浅灰石墙，顶部不是绝对水平直线，左右略向外展开。
- 墙面刻有多组人物、植物和行进场景的浅浮雕；V1 重点保留人物群的层次和大轮廓，不逐一复刻面孔和小物件。
- 浮雕墙下部有连续低基座，与四尊立像形成前后两层。
- 前置铜牌为低矮斜面矩形，外框较厚，置于浅灰石质支座上；牌面深棕黑铜色，带云纹边饰。
- 铜牌顶部语义标题为《家国》，实物采用传统右起横排；从正面画面左至右看到的字符位置是“国、家”。标题采用接近碑刻的隶书，不得使用现代无衬线字体；元数据和旁白不得误写成“国家”。正文较小，V1 可用低清原创浮雕线表示，待文字审核后再决定是否做可读贴花。

## 5. 材质与真实配色

- 人物、浮雕墙和基座：浅暖灰至灰白石材，哑光、高粗糙度，人物凸面略亮、凹槽略深。
- 铜牌：深棕黑色旧铜，边缘和凸字带暖铜高光，云纹为更明显的棕金色起伏。
- 石材不能做成纯白塑料或大理石镜面；保持细颗粒和轻微色差。

## 6. 推断、文字和禁止

- 四尊人物背面、浮雕墙背面和脚部遮挡处为 `INFERRED_LOW_DETAIL`，按整体姿态和服装体积闭合。
- 官方资料确认四尊雕像人物为陈宝仓、朱枫、吴石、聂曦，但没有给出当前照片视角下的左右姓名顺序；不得仅凭外形把姓名绑定到四种姿态。
- 不制作鲜花、花圈、祭品和照片水印，不将夜景照明烘焙进颜色。
- 不把浮雕墙做成完全平面的照片贴图；至少保留主要人物群的真实浅浮雕起伏。
- 不新增第五尊立像，不改变四人从左到右的姿态关系。
